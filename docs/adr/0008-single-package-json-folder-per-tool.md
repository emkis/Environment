# One root package.json/tsconfig, folder-per-tool under packages/

`chest` is the first thing in this repo to need an external dependency (e.g. `@clack/prompts`) — `ide`, `llmt`, and `vspeed` currently import only Bun/Node built-ins. We considered full Bun workspaces (a `package.json` per tool, independently declared dependencies) for proper isolation between the Independent tools and chest's Engine, but rejected it as premature for four small tools, three of which have no dependencies at all. Instead: one root `package.json` and `tsconfig.json` cover every tool under `packages/<name>/`, giving one shared dependency list and one type-check across the whole repo. If a specific tool later needs real isolation (a conflicting dependency version, say), that tool alone graduates to its own `package.json` under a workspace at that point — not paid upfront for tools that don't need it.
