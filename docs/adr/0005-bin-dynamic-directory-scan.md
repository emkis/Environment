# bin/ is synced by dynamic directory scan, not one Entry per file

This is the one deliberate exception to "every Entry is explicit" (ADR-0003). Files in `bin/` were previously synced by a separate `sync-bins` script that blindly `rm`'d and recopied the whole directory with no diffing, and the recurring friction — forgetting to resync after editing or adding a bin script, on either machine — was a primary motivation for this whole rewrite. Making each bin script its own explicit `config` Entry would just move that same friction into the Manifest (a new script still wouldn't be picked up until a Manifest line was added for it). Instead, `bin/` is walked at runtime and every file in it is diffed against its target path automatically, so a new script just works on the next Sweep with no Manifest edit required.
